# 운동 기록 삭제 및 운동 마스터 목록 개별 삭제 구현 계획서

완료된 과거 운동 기록을 달력 화면에서 안전하게 삭제할 수 있는 기능과, '운동 추가하기' 화면에서 사용자가 등록한 운동을 목록에서 삭제할 수 있는 관리 기능을 추가합니다.

---

## 사용자 확인 및 확정된 핵심 결정 사항

> [!IMPORTANT]
> - **완료된 과거 기록 삭제 위치**: **달력 탭의 선택 날짜 상세 화면**에 "이 날짜의 운동 기록 삭제" 버튼 배치 (삭제 전 실수 방지 확인 팝업 제공).
> - **운동 마스터 목록 삭제 범위**: 운동 추가 모달에서 운동명을 삭제할 경우, **운동 추가 선택 목록(마스터 DB)에서만 제거**되고 이미 저장된 과거 세션 기록은 안전하게 보존됨.

---

## 1. 개요 및 핵심 기능 명세

1. **달력 탭 과거 완료 기록 삭제 (Delete Workout by Date)**
   - 달력에서 특정 날짜를 선택했을 때 하단 상세 카드에 해당 날짜의 운동 정보가 표시됨.
   - 해당 카드 상단 또는 하단에 **[이 기록 삭제] (Trash2 아이콘, 레드 포인트)** 버튼 추가.
   - 클릭 시 확인 팝업(`"YYYY-MM-DD의 운동 기록을 완전히 삭제하시겠습니까?"`) 출력.
   - 확인 시:
     - `workouts` 배열에서 해당 날짜 데이터 영구 삭제 및 `localStorage` 동기화.
     - 달력의 라임/앰버 상태 도트가 즉시 사라짐.
     - 만약 오늘 날짜의 기록을 삭제한 경우, 오늘 탭의 상태도 빈 운동 세션으로 초기화.

2. **운동 추가 모달 내 등록 운동 개별 삭제 (Delete Exercise from Master List)**
   - Today 탭의 **[운동 추가]** 모달 내에 나열되는 등록된 운동 목록 각 행 우측에 **삭제 아이콘(Trash2)** 추가.
   - 클릭 시 해당 운동명을 `exerciseList`에서 영구 제거 및 `localStorage`에 즉시 저장.
   - 실수로 인한 오작동 방지: 클릭 영역을 운동 추가(전체 행 클릭)와 분리하여 우측 휴지통 버튼 클릭 시에만 삭제 동작.
   - 사용자 확인 기준: 과거 완료된 기록 내의 해당 운동 데이터는 영향받지 않고 온전히 보존됨.

## 2. 인터페이스 및 상호작용 설계

## 3. 데이터 흐름 및 상태 관리

```
┌─────────────────────────────────────────────────────────────┐
│                           App.tsx                           │
│  - workouts State & saveWorkouts()                          │
│  - exerciseList State & saveExercises()                     │
└──────────────────────────────┬──────────────────────────────┘
                               │
               ┌───────────────┴───────────────┐
               ▼                               ▼
     onDeleteWorkout(date)           onDeleteExercise(name)
               │                               │
               ▼                               ▼
       [CalendarTab.tsx]                [TodayTab.tsx]
 (선택 날짜 카드에서 기록 삭제)      (운동 추가 모달에서 개별 삭제)
```

1. `handleDeleteWorkout(dateStr: string)` in `App.tsx`:
   - `workouts.filter(w => w.date !== dateStr)` 실행 후 저장.
   - 만약 삭제 대상이 오늘 날짜라면 `todayWorkout`을 빈 세션으로 리셋.
2. `handleDeleteExercise(name: string)` in `App.tsx`:
   - `exerciseList.filter(e => e.trim().toLowerCase() !== name.trim().toLowerCase())` 실행 후 저장.

## 4. 검증 계획

1. **달력 기록 삭제 검증**:
   - 달력에서 과거 완료일(예: 3일 전 풀세션) 선택 -> [기록 삭제] 클릭 및 확인 -> 달력 도트 즉시 제거 및 상세 화면이 '운동 기록 없음'으로 갱신되는지 확인.
2. **운동 추가 목록 삭제 검증**:
   - 새 운동(예: '테스트 프레스') 등록 -> 운동 추가 모달에서 해당 항목 우측 휴지통 클릭 -> 목록에서 즉시 제거되는지 확인.
   - 기존 완료된 세션 기록 및 히스토리는 그대로 남아있는지 확인.
