# IronLog 모바일 APK 네이티브 내보내기·진동·음량 및 휴식 타이머 유지 개선 계획

안드로이드 APK 설치 환경에서 동작하지 않던 파일 내보내기와 진동 알림을 모바일 네이티브 브릿지로 전환하고, 작게 들리던 알림음 출력을 스마트폰 스피커에 맞게 대폭 증폭하며, 사용자가 설정한 휴식 타이머 기본 시간(프리셋 및 커스텀 초 입력)이 다음 세트와 앱 재실행 후에도 그대로 유지되도록 개선합니다.

---

## 사용자 확인 및 핵심 결정 사항

> [!IMPORTANT]
> 사전 질문에서 확인해 주신 선택 사항을 최우선 기준으로 반영했습니다. 계획 내용을 검토하신 뒤 승인해 주시면 즉시 구현을 진행합니다.

- **확정 결정 1 — APK 파일 내보내기 방식**: CSV 내보내기 및 전체 백업 실행 시 임시 파일을 생성한 뒤 **안드로이드 시스템 공유 창(Share Sheet)**을 즉시 띄워, 내 파일(Download 등 원하는 폴더), 카카오톡, 구글 드라이브, 메일 등 저장할 앱이나 위치를 직접 선택할 수 있게 합니다.
- **확정 결정 2 — 휴식 타이머 시간 유지 범위**: **프리셋 버튼(`45초`, `1분`, `1.5분`, `2분`, `3분`) 선택**과 **직접 초 단위 입력(예: `70초`)**은 다음 세트 및 앱 재접속 시에도 기본 휴식 시간으로 영구 유지하며, **`-15초` / `+15초` 버튼**은 현재 진행 중인 이번 세트에만 일시적으로 적용합니다.
- **확정 결정 3 — 네이티브 진동 알림 방식**: 세트 완료 체크 시의 잔진동은 제거하고, **휴식 타이머 카운트다운이 종료되는 시점에만 강한 연속 네이티브 진동**(및 설정 화면의 진동 테스트)이 울리도록 집중합니다.
- **기본 설정 음량 및 출력 강화**: 신규 기본 알림 음량을 **100%(최대)**로 상향하고, 오디오 합성 엔진에 마스터 증폭 및 다이내믹 컴프레서를 적용해 스마트폰 미디어 볼륨을 과도하게 높이지 않아도 헬스장 소음 속에서 또렷하게 들리도록 개선합니다.

## 1. 개요 및 핵심 컨셉

- **핵심 개선 내용**:
  1. **네이티브 공유 기반 데이터 내보내기**: 웹 브라우저 전용 다운로드 링크 대신 모바일 앱 캐시 저장소와 안드로이드 시스템 공유 시트를 연동하여 APK에서도 유실 없이 CSV 스프레드시트와 백업 파일을 내보냅니다.
  2. **하드웨어 진동 엔진 및 권한 연동**: 웹뷰에서 무시되던 브라우저 진동 호출을 안드로이드 네이티브 햅틱 엔진과 시스템 진동 권한으로 교체해 휴식 종료 시 확실한 손끝/주머니 진동을 전달합니다.
  3. **고출력 알림음 합성 파이프라인**: 순수 정현파 중심의 낮은 게인 구조를 개선하여 풍부한 배음과 마스터 컴프레서 증폭을 거친 고음량 알림음을 재생합니다.
  4. **맞춤 휴식 시간 기억 시스템**: 운동 중 바꾼 프리셋이나 직접 입력한 초 단위 시간(예: `70초`)을 즉시 기본값으로 저장하여 매 세트마다 `1.5분`으로 초기화되던 불편을 해소합니다.
- **대상 사용자 및 사용 환경**: 음악이나 주변 소음이 있는 헬스장·홈짐에서 스마트폰 APK 앱으로 세트를 체크하고 화면을 보지 않은 채 휴식 타이머 알림을 기다리는 웨이트 트레이닝 사용자.
- **핵심 가치**: 세트 간 조작 횟수를 최소화하고, 스마트폰을 내려놓거나 주머니에 넣은 상태에서도 휴식 종료를 놓치지 않으며, 기록 데이터를 언제든 원하는 폴더나 클라우드로 안전하게 보관할 수 있습니다.

## 2. 사용자 경험 및 시각적 디자인

### 주요 사용자 흐름 (Key User Flows)

1. **휴식 타이머 프리셋 및 커스텀 초 설정·유지 흐름**:
   - **운동 중 변경**: 오늘 탭에서 세트 완료를 체크하면 하단 플로팅 휴식 타이머 바가 열리며 **마지막으로 저장된 기본 휴식 시간**으로 카운트다운을 시작합니다.
   - **프리셋 선택**: 하단 프리셋(`45초`, `1분`, `1.5분`, `2분`, `3분`) 중 `45초`를 탭하면 즉시 45초로 재시작됨과 동시에 기본 휴식 시간이 `45초`로 저장되어 다음 세트 체크 시에도 `45초`로 시작합니다.
   - **직접 초 입력 (`커스텀`)**: 프리셋 우측의 **[직접 입력]** 버튼을 탭하면 인라인 숫자 입력창(초 단위, 예: `70`)이 나타나며, `70`을 입력하고 **[적용]**(또는 완료 키)을 누르면 타이머가 `1:10`으로 즉시 시작되고 이후 모든 세트의 기본 휴식 시간이 `70초`로 유지됩니다. 설정 탭에서도 기본 휴식 시간을 동일하게 확인·변경할 수 있습니다.
   - **일시 조정 (`-15초` / `+15초`)**: 상단 우측 `-` / `+` 버튼 클릭 시 현재 세트의 남은 시간과 목표 시간만 15초 단위로 증감하며, 저장된 기본 휴식 시간은 변경하지 않습니다.

2. **휴식 종료 알림(고출력 사운드 & 강한 연속 진동) 흐름**:
   - 세트 완료 체크 시에는 경쾌한 확인음만 울리고 진동은 발생하지 않습니다.
   - 휴식 타이머가 `0:00`에 도달하면 증폭된 알림음(체육관 비프, 디지털 차임, 복싱 벨, 소프트 펄스 중 선택된 톤)이 또렷한 음량으로 재생됨과 동시에, 안드로이드 네이티브 진동 모터가 **강하고 묵직한 연속 다단 진동 패턴**을 울려 휴식 종료를 확실히 알립니다.

3. **APK 데이터 내보내기(CSV & 백업) 흐름**:
   - 설정 탭의 **[CSV 내보내기]** 또는 **[JSON 전체 백업]** 버튼을 탭합니다.
   - APK 환경에서는 즉시 안드로이드 하단 **시스템 공유 창(Share Sheet)**이 올라오며, 사용자는 '내 파일에 저장(Download 폴더 등 선택)', '구글 드라이브', '카카오톡 나에게 보내기' 등 원하는 대상을 직접 선택해 저장을 완료합니다. (일반 데스크톱/모바일 웹 브라우저에서는 기존 다운로드 동작을 유지합니다.)

### 시각적 아이덴티티 및 모바일 터치 에르고노믹스

- **디자인 무드 및 컬러 시스템**:
  - 기존의 다크 애슬레틱 유틸리터리언 테마를 일관되게 유지합니다: 깊은 슬레이트 다크 배경(`#0B0D12`), 단일 레벨 카드 서피스(`#141720` 및 `#1B202D`), 헤어라인 보더(`#262D3D`), 핵심 액션 포인트인 앰버(`#F59E0B`) 및 완료 상태 포인트인 라임(`#84CC16`)의 60-30-10 배분을 준수합니다.
- **타이포그래피 및 숫자 정렬**:
  - 타이머 카운트다운(`1:10`), 프리셋 라벨, 커스텀 초 입력 필드는 모두 고정폭 숫자(`font-mono tabular-nums`)를 적용하여 초가 줄어들 때 레이아웃 흔들림이 없도록 유지합니다.
- **원핸드 썸존(Thumb-Zone) 및 공간 규칙**:
  - 하단 플로팅 휴식 타이머 바 내의 프리셋 버튼과 **[직접 입력]** 컨트롤은 한 손 엄지 조작 시 오터치를 방지할 수 있도록 충분한 터치 영역과 단일 행 스크롤 구조를 유지합니다.
  - 커스텀 초 입력 시 별도의 전체 화면 모달로 시선을 끊지 않고, 타이머 바 내부에서 간결하게 펼쳐지는 인라인 입력 바(`초` 단위 명시, `5초 ~ 600초` 범위 검증)로 구성해 상하단 고정 영역 비율이 과도하게 커지지 않도록 관리합니다.
- **인터랙티브 피드백 및 상태 알림**:
  - 내보내기 진행 중 중복 탭 방지 상태 표시 및 공유 완료 후 명확한 인앱 안내 토스트를 제공합니다.
  - 타이머 프리셋 또는 커스텀 초가 현재 기본값으로 저장되어 있을 때 활성 테두리와 앰버 하이라이트로 명확히 구분하며, `-15/+15`로 일시 변경된 상태에서는 기본값 배지가 덮어씌워지지 않도록 시각적으로 분리합니다.

## 3. 주요 제품 결정 및 트레이드오프

- **결정 1: 안드로이드 네이티브 파일 캐시 + 시스템 공유 시트(Share Sheet) 연동**
  - *선택한 방식*: 모바일 네이티브 환경 감지 시 앱 전용 캐시 디렉터리에 UTF-8(CSV의 경우 한글 깨짐 방지 BOM 포함) 파일을 기록한 후 네이티브 공유 인텐트에 파일 경로를 전달합니다.
  - *이유*: 안드로이드 최신 버전의 저장소 보안 정책(Scoped Storage)으로 인해 웹뷰 내부의 가상 메모리 링크(`blob:`) 다운로드는 무시되거나 실패합니다. 반면 캐시 파일 기반 네이티브 공유 창은 별도의 위험 저장소 권한 요청 없이도 사용자가 '내 파일(Download 폴더 포함)', 클라우드, 메신저 어디든 즉시 저장할 수 있어 가장 안정적이고 직관적입니다.
  - *고려한 대안*: 공용 문서 폴더에 강제로 자동 저장하는 방식은 안드로이드 버전별 권한 충돌이 잦고 사용자가 저장 위치를 알기 어려워 제외했습니다.

- **결정 2: 휴식 시간 영구 저장 동작과 일시 조정 동작의 명확한 분리**
  - *선택한 방식*: 프리셋 선택 및 커스텀 초 입력은 전역 설정의 기본 휴식 시간을 즉시 갱신·영구 저장하고, `-15초`/`+15초` 버튼은 활성 타이머의 로컬 상태만 변경합니다.
  - *이유*: 고중량 세트 직후 일시적으로 숨을 고르기 위해 `+15초`를 누른 것까지 다음 세트의 기본값으로 굳어지면 오히려 불편해집니다. 사용자의 의도적인 기준 시간 변경(프리셋·직접 입력)만 기억하는 것이 실제 운동 흐름에 가장 부합합니다.

- **결정 3: Web Audio 마스터 컴프레서 및 다중 배음(Harmonics) 합성**
  - *선택한 방식*: 모든 알림음 출력단에 다이내믹 컴프레서(리미터 역할 겸용)와 프리앰프 게인 노드를 배치하고, 스마트폰 소형 스피커에서 잘 들리는 중·고역대 배음 파형을 보강하며 기본 볼륨 설정값을 100%로 상향합니다.
  - *이유*: 기존 코드는 단일 파형에 `0.25 ~ 0.35` 수준의 낮은 진폭 계수를 곱해 최대 볼륨에서도 실제 출력 에너지가 25% 미만이었습니다. 컴프레서와 배음 레이어링을 적용하면 디지털 클리핑(찢어짐) 없이 체감 음량을 3배 이상 크고 선명하게 끌어올릴 수 있습니다.

- **결정 4: 휴식 종료 시점 전용 네이티브 연속 진동 패턴**
  - *선택한 방식*: 안드로이드 매니페스트에 하드웨어 진동 권한을 명시하고, 네이티브 햅틱 브릿지를 통해 휴식 종료 시 약 1.5초간 이어지는 강한 다중 장펄스 진동(예: 400ms 강진동 3회 연속)을 구동합니다.
  - *이유*: 웹 표준 진동 함수는 안드로이드 웹뷰에서 차단되거나 단발성 미세 틱에 그칩니다. 네이티브 브릿지로 긴 호흡의 연속 진동을 순차 호출해야 기기를 바닥에 두거나 주머니에 넣었을 때도 명확히 인지할 수 있습니다.

### 데이터 모델 및 상태 전략

- **환경 설정 상태 (`Settings`)**:
  - `defaultRestSeconds` (숫자, 초기 기본값 `90`, 사용자 변경 시 `5 ~ 600` 범위의 프리셋 또는 커스텀 초 값으로 즉시 영구 저장).
  - `soundVolume` (숫자, 신규 기본값 `1.0`으로 상향; 기존 저장 데이터가 기본 구버전 값 `0.8`인 경우에도 충분한 음량이 확보되도록 오디오 엔진 기본 출력 게인 자체를 대폭 상향).
  - `soundEnabled`, `soundType`, `vibrationEnabled` (기존 설정과 완벽 호환).
- **플로팅 타이머 내부 상태**:
  - `totalSeconds` / `remainingSeconds`: 새로운 세트를 체크할 때마다 전역 `defaultRestSeconds` 값으로 초기화되어 카운트다운 시작.
  - `isCustomInputOpen` / `customSecondsInput`: 타이머 바 내 인라인 초 입력 UI 토글 및 입력값 검증 상태.

### 인터랙티브 컴포넌트 및 핸들러 매핑

1. **플로팅 휴식 타이머 바**:
   - **프리셋 클릭 핸들러**: 선택된 초(`45`, `60`, `90`, `120`, `180`)로 현재 타이머를 즉시 리셋·시작하고, 상위 설정 업데이트 핸들러를 호출해 `defaultRestSeconds`를 영구 저장합니다.
   - **커스텀 초 입력 제출 핸들러**: 사용자가 입력한 초 숫자를 검증(최소 5초 ~ 최대 600초 클램핑)한 뒤, 현재 타이머에 즉시 반영·시작하고 `defaultRestSeconds`에 영구 저장합니다. 만약 기본 프리셋에 없는 값(예: `70초`)이 저장되어 있다면 프리셋 행에 활성 상태의 커스텀 배지 버튼(`70초 · 직접 설정`)으로 함께 표시해 현재 기본값을 한눈에 확인할 수 있게 합니다.
   - **`-15초` / `+15초` 핸들러**: `remainingSeconds`와 `totalSeconds`만 증감시키며 전역 `defaultRestSeconds`는 수정하지 않습니다.
2. **오늘 운동 뷰 (세트 완료 체크)**:
   - 완료되지 않은 세트를 체크할 때 세트 완료 확인음만 재생하고 기존의 짧은 진동 호출은 제거한 뒤 휴식 타이머 시작 신호를 전달합니다.
3. **설정 관리 뷰**:
   - 알림 및 타이머 섹션에서 현재 유지 중인 기본 휴식 시간(초)을 확인·직접 변경할 수 있는 컨트롤을 함께 제공하여 운동 전에도 원하는 초로 세팅할 수 있게 합니다.
   - CSV 내보내기 및 JSON 전체 백업 버튼을 모두 비동기 핸들러로 연결하여 안드로이드 공유 창 호출 결과(공유 완료 / 사용자 취소 / 오류 안내)를 깔끔하게 처리합니다.
4. **클라우드 APK 자동 빌드 호환성**:
   - 추가되는 모바일 네이티브 플러그인(파일시스템, 시스템 공유, 햅틱 진동)과 안드로이드 진동 권한 설정이 GitHub Actions 기반 APK 자동 빌드 및 동기화 과정에서 누락 없이 포함되도록 구성합니다.
